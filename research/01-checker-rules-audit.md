# Rules-Lawyer Analysis of `utils.py` (ground truth) — OGC 2026

All line refs: `/Users/vedantmoghe/Downloads/optichallenge/ogc2026/baseline/utils.py`. All claims below were verified by executing the actual checker (shapely 2.0.7 local; server 2.1.2, both GEOS/OverlayNG).

## CONFIRMED FACTS

1. **Violation requires strictly positive interior overlap area.** `inter.area > 0` at L535 (Stage 4), L713 (entry), L809 (exit). Edge/point contact is feasible (verified end-to-end: two 4×4 squares flush at x=0/x=4 pass all 5 stages). PDF §1.6.3 (`int(P)∩int(P)=∅`) agrees.
2. **AABB prefilter uses strict `<`** (L458 `_bb_overlap`). Pairs whose float AABBs merely *touch* are never shapely-checked at all — touching-AABB contact is unconditionally safe.
3. **Crane rule = j ≥ k, existing-block layer j vs moving-block layer k** (L703, L799). Empirically confirmed: a 2-layer block T can enter over a co-present 1-layer block S with T.layer1 overhanging S.layer0 (`check_entry` returns `[]`); afterwards S can neither enter nor exit while T is present (obstruction `new_layer=0, exist_layer=1, kind=sweep`), while T exits freely.
4. **Stage 4 checks ONLY same-index layers k vs k, up to `min(K_a,K_b)`** (L521), only for time-overlapping pairs under the half-open model `[a,e)` (L1159-61, L1272-74). Persistent cross-layer plan-view overlap between co-present blocks is *never* checked statically — only at ENTRY/EXIT events (Stages 2/3/5). Verified: a solution with a standing overhang passes.
5. **Same-time-point semantics.** Stage 2 present-set: `other.entry < t_entry < other.exit` (L1182) — same-day entrants AND same-day exiters excluded. Stage 3 identical (L1226). Stage 4 half-open intervals make `exit@t` and `entry@t` non-overlapping. Stage 5 replays ops **in our listed order** per time key (L1300-1391), requiring all EXITs (across ALL bays, scanned per time-key list, L1302-10) before any ENTRY; EXIT removes from `bay_present` before subsequent ENTRY checks (L1391).
6. **Same-day choreography verified through `check_feasibility`:** (A) exit A + enter B into A's exact spot same day → feasible; (B) ENTRY listed before EXIT same day → Stage-5 violation; (C) overhang pair both ENTER same day, base listed first → feasible; (D) overhanger listed first → Stage-5 sweep violation; (E) both EXIT same day, overhanger listed first → feasible; (F) base first → violation; (G) base exiting strictly *earlier* under a standing overhang → Stage-3 violation.
7. **Induced precedence structure (b):** if A.layer_j overlaps B.layer_k in plan view with j > k, then co-presence forces **interval nesting** `[ENTRY_A, EXIT_A] ⊆ [ENTRY_B, EXIT_B]` — the higher-layer owner A is the *inner/LIFO* element (must enter after B, exit before B), with boundary equality legal via same-day ordering (base-ENTRY listed before A's, A's EXIT listed before base's). Mutual overhang (overlaps in both index directions) or any same-index overlap ⇒ the pair can never be co-present: whoever enters second is blocked at Stage 5 regardless of order (verified). **For K=1 vs K=1, no plan-view overlap is ever legal while co-present**; disjoint intervals (including exit@t/enter@t) reuse space freely.
8. **Rounding (c):** `int(round(x))` at L1154-55 (Stage ≥2 blocks), L1334-36, L1343-45 (Stage 5). Python banker's rounding (2.5→2, 3.5→4); float `x=3.6` verified to place at 4. `x`/`y` default to 0.0 and `orient_idx` to 0 if omitted (L1073-75). Positions are effectively integers; fractional placement is impossible. Time keys parsed via `float(int(t_str))` (L1047) — a key like `"3.0"` is an immediate infeasibility; emit canonical decimal-int strings only. **Out-of-range `block_id` in an ENTRY crashes the checker** (uncaught IndexError at L1117); negative ids alias via Python indexing — never emit.
9. **Time horizon (e): none.** No upper bound on any time anywhere in the file. Verified: serialized fallback with keys > 10^6 is feasible (`prob_17` n=300 and `prob_40` n=250, objective ~10^12 but `feasible=True`). Fallback recipe confirmed: per block, pick any (bay, orientation) whose all-layer bbox fits (some blocks do NOT fit every bay — my first bay-0-only attempt failed on 7/300 blocks; must search bays), place alone in disjoint windows. A submission need never be infeasible.
10. **Stage 1** (L1089-1135): duplicate ENTRY/EXIT = violation; every id 0..n-1 must have both ops; bay/orient range checks; `entry ≥ release − 1e-6`; `exit − entry ≥ P − 1e-6`. EXIT's `bay_id` must match ENTRY's (L1323, Stage 5).
11. **Containment** uses the all-layer bounding box, non-strict `≤` (L262-66): flush against the bay wall is legal; overhanging upper layers must also stay in-bay. **Reference point = first vertex of layer 0, NOT the bbox corner** — vertices can be negative (prob_1 block 0 has y=−0.3357), so legal x,y ranges are shape-dependent and x,y may lie outside naive `[0, W−w]`.
12. **Checker cost (g):** measured `check_feasibility` = **0.02 s (n=100) / 0.04–0.06 s (n=300)** on real baseline solutions (`lru_cache(8192)` polygon memoization, L165). You can afford ~15–25 full checks/sec/core — use it as a validation gate and occasional LNS acceptance test; inner loops should still use incremental `check_entry/check_exit(fast=True)` (sub-ms per event).
13. **Objectives** (L1397-1430): `obj1` raw tardiness sum; `obj2 = floor(max pairwise |u·load|)`, loads = total-ever workload per bay (time-independent, L1412); `obj2=0` if m=1 (L1428); `obj3` pure assignment regret; weights default 1.0 if absent.
14. **Numerical sliver risk (d), quantified:** cross-block flush along a fractional coordinate is mathematically possible only when the touching coordinates have *equal 1e-4 fractional parts* (integer positions). Monte-Carlo over 200k such flush configurations: **95.7% exact-double equality (safe, AABB prefilter skips), 2.15% 1-ulp gap (safe), 2.15% 1-ulp OVERLAP → intersection area ~1e-14 > 0 → server violation.** Fully deterministic IEEE754 — reproducible with local utils. Diagonal shared-edge contact with collinear differently-provenanced vertices returned area 0 in tests, but don't design for it.

## TOP 5 EXPLOITABLE PROPERTIES (ranked for solver design)

1. **Two-level decomposition:** Z2+Z3 are pure functions of the assignment vector (L1404-14); given assignments, bays are fully independent weighted-tardiness packing problems → assignment master (Z2/Z3 deltas exact and O(1) per move) + 4-way-parallel per-bay slaves. Magnitudes (f): sumL/m ≈ 2.6k–12k, u≈1; baseline leaves obj2 = 389–5376 (w2·obj2 = 2.7k–21.5k ≈ up to 2.2 tardy-days); avg regret-to-2nd-best bay is 30–75 pref-points → w3·regret ≈ 4k–30k *per block*, often ≥ 1 tardy-day — **Z3 is per-block comparable to Z1; Z2 deserves only a coarse rebalancing pass using preference-indifferent blocks** (marginal obj2 unit costs w2∈[1,10]; `floor` matters only for ties).
2. **Same-day EXIT→ENTRY space reuse (zero turnaround):** the day-t bay state for entries is the post-exit state; schedule JIT chains (exit at due date, successor enters same day), multi-block cascades, and same-day nest construction/unwinding via our chosen op order.
3. **Overhang nesting as free area:** upper layers cost plan area only against same-index layers of co-present blocks + a LIFO interval-nesting DAG. Pack layer-0 footprints hard, treat upper layers as soft constraints priced by the nesting they induce; roof long-stay tall blocks over short-stay inner blocks whose intervals nest.
4. **Anytime safety: unbounded horizon + verified constructive fallback** — always hold a feasible incumbent (serialized far-future placement, fits-aware bay choice); the −1 catastrophic outcome is entirely avoidable; spend 100% of remaining wall-clock on improvement.
5. **Zero-clearance packing with a cheap exact oracle:** strict `area>0` + strict AABB prefilter make integer-coordinate flush contact certifiably safe; the 40–60 ms full checker and importable primitives (`check_entry(fast=True)`) let the solver self-certify placements using the *server's own arithmetic*. **Margin policy:** (i) always final-gate with bundled `check_feasibility`; (ii) in-solver contact acceptance only via checker-identical arithmetic (translate `v + int`, same shapely calls — deterministic cross-machine); (iii) treat fractional-fractional flush (equal 1e-4 fractional parts) as dangerous (~2% 1-ulp overlap): verify or nudge 1 unit / dilate internal no-fit polygons by 1e-3; integer-edge contact and ≥1e-4 gaps are safe by construction.
